# 배터리 저전압 진단(BLV) 기능사양서

문서 번호: BCM-FS-BLV / 개정 1.3

## 1. 개요

본 기능은 차체 제어기(BCM)에서 10ms 주기로 배터리 전압을 감시하여 저전압 고장을 판정하고,
고장 코드(DTC B1A00)를 기록하며 운전자에게 저전압 경고등을 요청한다.

## 2. 입출력 신호

| 신호 | 방향 | 설명 | 범위/단위 |
|---|---|---|---|
| BattVolt | 입력 | ADC로 측정한 배터리 전압 (분압 보정 후) | 0 ~ 20000 mV |
| IgnSts | 입력 | 이그니션 상태 | OFF / ACC / ON / START |
| BlvWarnLamp | 출력 | 저전압 경고등 요청 | 0: 소등, 1: 점등 |
| DTC B1A00 | 출력 | 배터리 저전압 고장 | Dem 이벤트 상태 FAILED / PASSED |

## 3. 기능 요구사항

SWR-BLV-001 진단 실행 조건
진단은 IgnSts가 ON일 때 수행한다.
IgnSts가 START인 동안에는 크랭킹에 의한 일시적 전압 강하가 발생하므로 진단을 중단하며, 이때 고장 카운터와 정상 카운터는 현재 값을 유지한다.

SWR-BLV-002 저전압 판정
배터리 전압이 9000mV 이하이면 저전압 조건으로 판단한다.

SWR-BLV-003 고장 확정
저전압 조건이 2초 동안 연속으로 유지되면 고장으로 확정하고 DTC B1A00을 FAILED로 보고한다.

SWR-BLV-004 경고등 출력
고장이 확정된 상태에서는 경고등을 점등한다. 고장이 해제되면 경고등을 소등한다.

SWR-BLV-005 고장 해제
고장 확정 이후 배터리 전압이 10500mV 이상인 상태가 5초 동안 연속으로 유지되면 고장을 해제하고 DTC B1A00을 PASSED로 보고한다.
고장 해제 시 고장 카운터는 0으로 초기화한다.

SWR-BLV-006 히스테리시스
배터리 전압이 9000mV 초과 10500mV 미만인 구간에서는 현재 진단 상태를 유지한다.

SWR-BLV-007 시동 후 진단 유예
IgnSts가 START에서 ON으로 전환된 후 3초 동안은 진단 판정을 유예한다.

SWR-BLV-008 입력 유효성
BattVolt 측정값이 무효(ADC 오류 값)인 경우 해당 주기의 판정을 수행하지 않는다.

SWR-BLV-009 초기화
제어기 초기화 시 고장 카운터, 정상 카운터, 진단 상태는 초기값으로 설정하고 경고등은 소등한다.
단, 이전 운전 사이클에서 확정된 DTC는 유지한다.

SWR-BLV-010 경고등 우선순위
진단 중단 조건(IgnSts = START)에서도 고장 확정 상태라면 경고등 점등을 유지한다.

## 4. 비기능 요구사항

- 진단 주기: 10ms
- 경고등 요청 지연: 고장 확정 후 100ms 이내
